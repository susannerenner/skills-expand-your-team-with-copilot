# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share individual activities on WhatsApp, Facebook, or X, or copy their links

## Sharing activities

Use the sharing buttons beneath an activity to send its link to friends. Social
sharing opens the selected service in a new tab; nothing is posted automatically.
Shared links open the activities page and bring the matching activity into view.
Sharing does not require a teacher login and includes only the activity name and
link, not student information.

If your browser cannot copy a link automatically, use **Copy link** and copy the
selected address shown beneath the buttons.
